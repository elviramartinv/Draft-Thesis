\subsection{Jet\texorpdfstring{$\to\tau_h$}{ -> tau h} misidentification: the Fake Factor method}
\label{subsec:bbtt_ff}
% CORE SECTION -- leading experimental systematic (25% of Delta mu).
% - Motivation: jet->tau_h rate is 1e-2 to 1e-3, poorly modelled in MC, and with two
%   b jets required the necessary MC statistics is prohibitive.
% - Three enriched CRs: QCD multijet (same charge, ~99% purity), ttbar (opposite
%   charge + inverted ellipse, ~95%), W+jets (same charge, pTmiss > 60 GeV,
%   m_T > 30 GeV, loose b-jet veto, ~80%).
% - Each split into ID / anti-ID by the Medium DeepTauVsJet WP; FF(pT, eta) is the
%   ID/anti-ID yield ratio after subtracting genuine-tau contributions, derived
%   per channel -> FF_MJ, FF_tt, FF_Wj.
% - Template region: same SR selection but the least isolated tau_h fails Medium.
%   Process fractions r_tt and r_Wj from simulation, QCD fraction from data.
% - Combined:  FF = r_tt*FF_tt + r_Wj*FF_Wj + (1 - r_tt - r_Wj)*FF_MJ,
%   applied as an event weight to the template region.
% - Closure and validation region.
% -> code: get_ff_regions() l.3319, scripts/compute_FakeFactors.py,
%    compute_FFProcessRatios.py, compute_rFactors.py

\subsection{From ABCD to Fake Factors: the Run-2 heritage}
\label{subsec:bbtt_abcd}
% (2) MY OWN RUN-2 CONTRIBUTION. Keep it compact but do not undersell it.
% - The ABCD construction: region A = OS + isolated tau_h (signal region),
%   B = SS + isolated, C = OS + non-isolated (fails Medium, passes VVVLoose),
%   D = SS + non-isolated. QCD shape taken from C, normalisation from B/D.
%   -> code: get_qcd_regions() l.3280 keeps exactly these region names
%      (os_iso / os_inviso / ss_iso / ss_inviso)
% - The stability studies I carried out: the normalisation was tested by
%   redefining regions C and D with four alternative DeepTauVsJet working point
%   pairs (VVVLoose-VVLoose, VVLoose-VLoose, VLoose-Loose, Loose-Medium) and
%   checking the C/D ratio against a constant fit; the ABCD prediction was
%   compared with data-minus-background in a sideband defined by inverting the
%   elliptical mass cut; and the whole method was repeated in shifted regions
%   A'B'C'D' built on very loose working points, QCD-enriched and signal-poor.
%   Where the standard C/D disagreed with the constant fit, an extra normalisation
%   uncertainty was assigned. The arbitrariness of taking the shape from C rather
%   than from B was also covered by a dedicated uncertainty.
% - Why it was replaced for Run 3: ABCD gives one shape and one normalisation for
%   an inclusive "QCD" object, whereas the Fake Factor method resolves the fake
%   composition process by process and parametrises the transfer in (pT, eta).
%   Frame the transition as a refinement of the same idea (measure the fakes where
%   they dominate, transfer to where they do not), not as a repudiation.
% - DECISION PENDING: whether this stays a subsection here or is folded into
%   Sec. 6.6.4 as a set of paragraphs. Judge once written.
